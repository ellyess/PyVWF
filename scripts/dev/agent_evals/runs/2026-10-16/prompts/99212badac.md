## Proposal

**Claim:** The path collision found in the cluster-selection study's first run
is confined to that study, so only its contaminated rows need re-running.

**Mechanism:** A training run directory is keyed on the region code and the
run name. A study that varied something the path does not carry could write
two configurations' `factors_*.csv` into one directory, and `run_evaluate`
scores every `factors_*.csv` it finds. Two rows of the cluster-selection study
(DK and UK, onshore and offshore sharing `train-fold-<year>`) are known to have
been contaminated this way.

**Change:** A read-only audit, `scripts/analysis/undeclared_factors_audit.py`.
For every `run_manifest.json` under `output/` belonging to a training run, it
reads the declared counts from `manifest["correction"]["cluster_list"]`, where
`build_manifest` in `src/vwf/harness/provenance.py` writes them, lists the run
directory's `factors_*.csv`, parses the cluster count from each name, and flags
the run if any count is not declared. A run whose manifest declares no
`cluster_list` is reported as undeclared, never treated as clean. It prints the
number of runs audited, undeclared and flagged, and the flagged paths. Before
it is run on everything, it is run on the cluster-selection study's
contaminated DK and UK runs, which it must flag, and on one clean run of that
study, which it must not.

**Test:** Every training run under `output/` (about 220). No training or
scoring. Training and test years are those of each audited run; the audit does
not depend on them.

**Gates:** If no run outside the cluster-selection study is flagged, and the
known contaminated runs are, only that study's contaminated rows are re-run.
If any other run is flagged, its study is re-run too.

**Expected effect and size:** No run outside the study flagged, because every
earlier study put its varying dimension in the run path.

**Risks:** A run whose `factors_*.csv` names do not parse is reported, not
silently skipped.
