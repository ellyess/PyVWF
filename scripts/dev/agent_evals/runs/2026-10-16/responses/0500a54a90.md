**Verdict:** REVISE

**Blockers:**
1. **The threshold is the optimiser's own stopping tolerance.** `minimize(..., ftol=1e-6)` acts on the squared error, which is far below 1, so L-BFGS-B stops once an iteration improves it by less than 1e-6. An absolute residual of 1e-3 (1e-6 squared) is therefore a normal place to stop. The gate would refuse periods because of where the optimiser stopped, not because the observation cannot be matched. Observations the fit cannot reach already end on a bound or fail to converge, and both are refused today (`src/vwf/correction.py:331-344`). Fix: measure the residual distribution read-only first, then set the threshold from it.
2. **"After it returns" is not possible.** The function returns only the offsets dict, not the residual. The gate has to go inside `find_offsets_country_level`, after the bound check, using `result.fun`. If it goes before that check, the mocked `OptimizeResult` in `tests/test_country_offset_refusal.py:58` has no `fun` and the test breaks.
3. **The routing claim is unverified.** `country_obs_is_per_cluster` (`src/vwf/data.py:271`) counts distinct values exactly. Each cluster's `obs` is `sum(v*w)/sum(w)` (`src/vwf/metrics.py:53-57`), which can differ between clusters in the last digit when capacities are unequal. At the scorecard k, national rows could then go to the per-cluster solver and the gate would never run. The routing test uses equal capacities (`tests/test_country_zonal.py:187`). The routing is also decided once for the whole fit (`.any()`), not period by period.
4. **Provenance.** A hardcoded 1e-3 changes every national fit. Add a `[correction]` key that defaults to off (`src/vwf/harness/regions.py:116,287`). Pass it through `src/vwf/harness/driver.py:321,539`, `src/vwf/harness/hindcast.py:116` and the `fit` signatures in `src/vwf/harness/corrections.py`, and record it in the manifest.
5. **The pass gate cannot fail.** Allowing RMSE to rise by up to 0.002 tolerates more than the expected effect (under 0.001) and more than the gap between variants already called not meaningful (`docs/findings/method-country-level.md:331`). Pre-specify an improvement that the result must show.
