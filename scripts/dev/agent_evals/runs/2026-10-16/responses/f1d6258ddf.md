**Verdict: REVISE**

**Blockers**

1. **The 1e-3 gate sits on the optimiser's own stopping rule, not on periods that cannot be closed.** `find_offsets_country_level` (`src/vwf/correction.py:325-327`) minimises the squared CF error with L-BFGS-B, `ftol=1e-6`, `maxiter=50`. Because f is below 1, the stop condition is roughly an absolute drop in f of 1e-6 or less. A residual of 1e-3 gives f = 1e-6, so a fit can stop at that residual through tolerance alone. With N>1 offsets against one number, the surface is under-determined (`docs/findings/method-country-level.md` sections 7-8), and almost any target inside the bounds can be reached. Periods that truly cannot be reached already put an offset on a bound and are refused (lines 339-344). So the gate would mostly measure `ftol`, x0 and maxiter. Fix: first tighten the solver (`ftol` well below the gate squared, or solve the k=1 case with `_find_offset_bracketed`). Then log the residual distribution on training years only, and set the threshold before any run, in a commit.

2. **Two changes are bundled.** The router rewrite (`src/vwf/data.py:249-272`) and the gate are separate changes. If national rows are mis-routed today, the router fix alone changes the estimator and moves the scorecard rows. Fix: land the router change first, with evidence that `nunique` actually exceeds 1 on a real national frame, as its own change. Then test the gate against that baseline.

3. **The split does not exist.** The scorecard configs train 2015-2021 (IE 2017-2021) and test 2023 (`configs/regions/scorecard/*_country.toml`). The ENTSO-E source has no 2015-2020 window and no 2021 test file (`docs/findings/method-national-single-cluster-prereg.md`, "Blocked on data"). Fix: use the scorecard split, or state how the windows are made.

4. **The gates cannot test the claim.** "Worst training periods" is never checked. A pass needs only a low refusal rate and no harm, which a gate that refuses nothing also meets. No test-year resampling is given. Fix: add a gate that refused periods have larger training residuals or scalar-offset outliers. Add a bootstrap over test-year periods, and an effect size that has to beat it.

**Should fix**

- Country-level rows have no "scorecard k". The candidates are 1 or the grid's own count (prereg table).
- PT's capacity register is a known defect (same prereg). Refusals concentrated in PT would flag a data defect, not a bad fit. Exclude PT or report it separately.
- Report refused factors per row (the `min_accepted_years` majority rule, `src/vwf/data.py:873`), not only the share of periods refused.

**What would change my verdict**

A preregistration that:
- uses the scorecard split;
- tightens the solver first;
- fixes the threshold from training-only residuals;
- lands the router fix separately;
- has a gate the gate change could actually fail.
