**Verdict: REVISE.** The audit is worth building, but it can only find collisions that left extra files behind, so the gate overstates what a clean result shows. Note that this checkout is the older layout: `src/vwf`, with no `.importlinter`, no `tests/test_public_analysis_api.py` and no `src/vwf/AGENTS.md`.

**Blockers**
1. **The expected effect is already contradicted by the code.** `_run_dir` builds the path from the region code, the mode and the run name only, not the fleet mode (`src/vwf/harness/driver.py:183-185`). Two other drivers vary the fleet mode without putting it in `run_name`: `scripts/analysis/curve_library_study.py:256` (`run_name=condition`) and `scripts/analysis/cluster_sweep_cost.py:80` (`"sweep-cost"`). Fix: name these in the proposal and say how they are cleared.
2. **A clean result cannot clear a study.** If two colliding configurations declare the same counts, or the later one declares more, no extra file is left. The same holds for parallel processes. Fix: change the gate to "flagged means re-run". An unflagged run is unproven, not clean.
3. **Checking cluster counts alone misses some strays.** A stray `factors_season_5.csv` next to a declared k=5 would pass. Fix: compare `(time_res, num_clu)` pairs. Take them from the `fit_diagnostics` keys `"{time_res}_{num_clu}"` (`driver.py:279`), falling back to `cluster_list` x `time_slices`. Parse names the way the driver does, `stem.split("_")[1:3]` (`driver.py:388`).
4. **Finding runs by their manifests misses some.** `write_manifest_safe` can fail without writing anything (`src/vwf/harness/provenance.py:309`). Fix: list every directory that holds `factors_*.csv` and report any without a manifest. Select training runs by `run_mode == "train"`, not by directory name.
5. **The harm is in the scored rows, which the proposal does not check.** One stray variant changes the shared rows every variant is scored on (`_score_on_common_rows`, `driver.py:497-550`), so every number in that run moves, not only the stray row. Fix: also compare each evaluate run's `metrics.csv` (`num_clu`, `time_res`) with its own manifest's `correction`. Then use `trained_from` and `transfer_source_run` (`driver.py:453,853`) to list the affected evaluate and transfer runs.
