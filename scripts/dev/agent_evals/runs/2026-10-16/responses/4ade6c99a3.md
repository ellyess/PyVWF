**Verdict: REJECT.** The idea is worth keeping, but this design records the wrong file.

**Blockers**

1. **The audit picks a grid the code does not pick.** The proposal sorts a glob and takes the last match. AGENTS.md forbids exactly that ("Never sort a glob and take the last entry"). The code chooses the grid in `EntsoeFileSource._grid_points_candidates` (`/var/folders/hb/8jmqlr8502jd4_jj817kmrq00000gn/T/pyvwf-checkouts/a75ab221/src/vwf/sources/entsoe_files.py`, lines 66-87):
   - It tries `<c>_grid_points_{fleet_year}.csv` first, then falls back to the static `<c>_grid_points.csv`.
   - `fleet_year` is the test year for the test split and the last training year for the train split.
   So one figure uses two grids, one per split, and neither is the latest year on disk. The pattern `_20*.csv` also never matches the static fallback. A region running on the static grid would be reported "missing" even though the code uses it. Fix: key each row on (region, split, training years, test year) and get the path from `EntsoeFileSource(...)._grid_points_path()` itself.

2. **Point count cannot tell the grids apart.** method-country-level.md section 5 (`/var/folders/hb/8jmqlr8502jd4_jj817kmrq00000gn/T/pyvwf-checkouts/a75ab221/docs/findings/method-country-level.md`, line 252) says the yearly grids share one fixed point set and only the weights change. Point count is therefore the same across years, and the latest file's total capacity is wrong for any earlier split. Fix: record capacity per split and a content hash of each file.

3. **Old figures cannot be labelled from today's disk.** `build_manifest` (`/var/folders/hb/8jmqlr8502jd4_jj817kmrq00000gn/T/pyvwf-checkouts/a75ab221/src/vwf/harness/provenance.py`, lines 247-295) records no grid path or hash. The grid files have been regenerated since earlier runs (uniform grids replaced by fleet-weighted ones, section 5). Labelling the two Belgian figures, such as BE 0.340 to 0.020 in scorecard.md (line 487), with the file present now is a claim about the past with nothing to back it. Fix: add the resolved grid path and hash to the manifest going forward. Label old figures only where a manifest or the run's own output shows the grid. Otherwise mark them "grid unrecorded".

Write one that builds both splits for a region that has yearly files and for one that has only the static file, and asserts the audit's path equals the resolver's. The check must be shown to fail on each case (AGENTS.md: test a check both ways).
- State the training years and test year in every row. AGENTS.md requires it.
