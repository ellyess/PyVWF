## The problem

The comparison is not like for like. The affine column is read from an old
cluster sweep that the scorecard has since replaced, so it is not the current
in-region affine correction. And it is scored on the harness's common rows,
which leave out every unit in a cluster whose affine fit was refused, while
the model is scored on all its test rows; the left-out units are harder, so
the affine figure is flattered. A review that names either the superseded
source or the mismatch between the rows each arm is scored on identifies this
defect.

## The review

**Verdict:** REJECT

**Blockers**

1. **The gate is set after the result is known.** `docs/findings/method-physics-informed.md` (lines 229 and 261) already reports "Zero-shot Brazil matches Brazil's own fitted correction to 0.8%" (0.1062 against 0.1054). Picking Brazil and a 1.01 threshold "in advance" after that number was published is post hoc, so it cannot pass a gate. Fix: drop the claim, or preregister a gate over all five holdouts before any rerun.

2. **The two columns are scored on different rows.** `incumbent()` in `scripts/studies/physics-informed/e1_report.py` reads the harness `metrics.csv`, which uses the harness's common rows. The model column comes from `pyvwf/pinn/runs.py::score_on_common_rows`, which uses the common rows of the pinn conditions only. For Brazil the rerun scores 389 rows with uncorrected 0.13860 (`method-physics-informed-rerun-prereg.md`). The scorecard row has 140 scored complexes and uncorrected 0.130, with affine 0.097 (`scorecard.md` line 965). Against the current affine row, zero-shot is about 9% worse, not within 1%. The rerun also did not reproduce the affine column (findings, line 71). Fix: score affine and zero-shot together in one `score_on_common_rows` call, on the same fleet, ERA5 files and curve library.

3. **The margin is smaller than the seed noise.** Zero-shot Brazil is 0.10619 ± 0.00115 over five seeds, a spread of about 1.1%. That is larger than both the 1% margin and the 0.8% gap. Fix: any equivalence gate needs a margin well beyond the seed spread plus a unit bootstrap of the test year.

4. **The affine reference is degenerate and partly chosen on the test year.** The Brazilian fit has two failed offsets (`scorecard.md` line 1000). `incumbent()` also takes the minimum over time slices, which uses the test year. "Within 1% of a degenerate fit" is not evidence of skill.

**Should fix**

- The arm does not match the purpose. Affine in region is a ceiling, not the comparison for regions without data. The headline should rest on uncorrected and an affine transfer, which already pass (P1, R3).
- Brazil has observations, so it is not a target region. Report its coverage from `scripts/studies/physics-informed/d5_regime_coverage.py` before saying anything outside the covered range.
- "Affine lower in the other four" contradicts the findings table, where zero-shot beats affine-in-region in no holdout except BR. Check what is being predicted.

**What would change my verdict:** a new preregistration with an equivalence margin across all five holdouts (training and test years as in the proposal) that is larger than the seed and resampling spread. Both arms would be scored on the same common rows in one call, against a non-degenerate affine reference at a cluster count and time slice fixed in advance.
